# Background-Remover
An interactive Image Comparison Slider built with HTML, CSS, and JavaScript.

## 🚀Live Demo
https://anithakupppusamy.github.io/Background-Remover/

Users can move the slider horizontally to compare two versions of an image before and after.

## 🚀 Features

- Interactive image comparison effect
- Smooth mouse movement tracking
- Responsive layout
- Pure HTML, CSS, and JavaScript
- Lightweight and easy to customize

## 📸 Demo

Move the slider left or right to reveal the original image.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

```text
Background-Remover/

    ├── original.jpg

```

## ⚙️ How It Works

1. The background image is displayed inside the image container.
2. A second image is placed inside an overlay container (`.img-wrap`).
3. JavaScript tracks mouse movement over the image.
4. The overlay width changes dynamically based on the cursor position.
5. A vertical slider line and arrow indicate the comparison position.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/anithakuppusamy/anithakuppusamy.git
```

### Open the Project

Simply open `index.html` in your browser.

No additional installation or dependencies are required.

## 🎨 Customization

Replace the images inside the `images` folder with your own:

- `background.png` → Comparison image
- `original.jpg` → Original image
- `arrow.png` → Slider handle icon

You can also modify colors, dimensions, and animations in `style.css`.
